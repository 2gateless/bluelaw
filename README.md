# 법무법인(유한) 청률 모바일 웹 & PWA

법무법인(유한) 청률의 공식 모바일 웹 애플리케이션입니다. 스마트폰 화면에 최적화된 인터페이스를 제공하며, 모바일 브라우저 접속 및 홈 화면 앱 설치(PWA)를 모두 지원합니다.

- **서비스 주소**: [https://2gateless.github.io/bluelaw/](https://2gateless.github.io/bluelaw/)
- **저장소**: [https://github.com/2gateless/bluelaw](https://github.com/2gateless/bluelaw)
- **기술 스택**: React 19, Vite, Lucide Icons, Vanilla CSS, PWA (Service Worker)

---

## 📱 주요 기능

1. **홈 (소개 및 소식)**
   - 법인 인사말 및 철학 소개
   - 청률 공지사항 및 최근 소식 확인
   - 직통 전화 상담, 공식 네이버 블로그 방문, 지도 길찾기 바로가기

2. **변호사 소개**
   - **구성원 변호사 (15인)** 및 **소속 변호사 (2인)** 프로필 목록
   - 고해상도 최적화 프로필 사진(WebP)과 주요 경력 안내
   - '자세히 보기' 클릭 시 앱 내 맞춤 뷰어로 상세 이력 페이지 제공

3. **주요 업무분야**
   - 7개 핵심 분야(민사, 형사, 가사, 일반행정, 기업회생 및 파산, 조세, 중재)
   - 작은 화면의 스마트폰에서도 한눈에 파악할 수 있는 컴팩트 그리드 레이아웃
   - 각 분야 클릭 시 해당 전문 웹페이지를 모바일 프레임 맞춤 뷰어로 표시

4. **성공 사례**
   - 홈페이지에 등록된 **160여 건 이상의 성공사례 전수 수록**
   - **실시간 검색**: 사건명이나 키워드(예: 손해배상, 기각, 이혼, 회생 등)를 입력하면 즉시 필터링
   - **분야별 필터**: 민사, 형사, 가사, 일반행정/조세, 기업회생/파산 탭 분류
   - 항목 클릭 시 본문 확인 후 '← 뒤로' 버튼으로 간편히 목록 복귀

5. **문의 및 오시는 길**
   - 직통 전화 연결 (`tel:051-507-1001`)
   - 사무실 주소 및 네이버 지도 길찾기 연결
   - 업무 및 상담 시간 안내

6. **모바일 최적화 & PWA (Progressive Web App)**
   - **스마트폰 뒤로가기 버튼 완벽 연동**: History API를 통해 뒤로가기 시 앱이 바로 종료되지 않고 이전 메뉴나 목록으로 단계적 이동 (첫 화면에서만 앱 종료)
   - **홈 화면에 앱 추가(설치)**: Android / iOS 브라우저에서 '홈 화면에 추가' 또는 '앱 설치' 지원
   - **오프라인 지원**: Service Worker 캐싱을 통해 네트워크가 불안정해도 기본 데이터 즉시 표시

## 💡 유지보수 및 기억해야 할 사항

### 1. 정보 수정 방법 (데이터 분리 구조)
앱의 주요 텍스트와 목록은 `src/data/` 폴더 내 JSON 파일로 분리되어 있어 소스 코드를 몰라도 손쉽게 변경할 수 있습니다.

| 수정할 대상 | 파일 위치 | 설명 |
|---|---|---|
| **변호사 정보** | [`src/data/lawyers.json`](./src/data/lawyers.json) | 변호사 추가, 이름, 직함, 경력, 사진 경로, 링크 수정 |
| **업무분야** | [`src/data/services.json`](./src/data/services.json) | 업무분야 명칭, 아이콘, 연결 웹페이지 URL 수정 |
| **법인 정보/공지** | [`src/data/company.json`](./src/data/company.json) | 대표전화, 주소, 인사말, 공지사항 목록 수정 |

> **새 변호사 사진 추가 시 팁**:
> 1. 사진 파일을 [`public/images/`](./public/images/) 폴더에 넣습니다. (권장 비율 약 200×280)
> 2. `src/data/lawyers.json`의 `photo` 경로에 파일명을 적어주면 자동 반영됩니다.

---

### 2. 성공사례 자동 동기화 (Monthly Sync)
- **동작 주기**: **매월 18일 오전 09:00 (한국 시간)**에 GitHub Actions가 자동으로 실행됩니다.
- **동작 내용**:
  1. [`scripts/sync_cases.py`](./scripts/sync_cases.py)가 `bluelaw.co.kr`의 성공사례 게시판을 전체 크롤링합니다.
  2. 새로운 사례가 있으면 `cases.json`을 자동으로 갱신하고 GitHub에 커밋·재배포합니다.
  3. `last_synced.txt`에 동기화 시점을 기록하여 GitHub의 60일 비활성 워크플로우 정지 정책을 방지합니다.
  4. 만약 사이트 점검이나 일시 차단으로 결과가 50건 미만으로 떨어지면 기존 데이터를 보호하기 위해 덮어쓰지 않는 안전 게이트가 동작합니다.
- **수동 즉시 동기화**:
  홈페이지에 새 글이 많이 올라와 바로 반영하고 싶을 때는 GitHub 리포지토리의 **Actions → Build and Deploy to GitHub Pages → Run workflow** 버튼을 누르면 즉시 동기화 및 배포됩니다.

## 🛠️ 개발 및 빌드 환경

### 설치 및 로컬 실행
```bash
# 패키지 설치
npm install

# 로컬 개발 서버 실행 (브라우저에서 실시간 확인)
npm run dev

# 프로덕션 빌드 (dist/ 폴더 생성)
npm run build

# 빌드 결과물 미리보기
npm run preview
```

### 배포 파이프라인
- `main` 브랜치에 코드를 푸시하면 [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml) 워크플로우가 자동으로 실행되어 `dist/` 폴더를 GitHub Pages로 빌드 및 배포합니다.
